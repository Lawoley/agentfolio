For builders: the attestation API

Any contract or app can ask AgentFolio one question — is this address a genuine, active, endorsed Agent ID holder? — with a single read:

reputationOf(address) → (holder, member, hasProfile, totalDays, streak, endorsements, lastActive)

isVerifiedActive(address) → bool — holds an Agent ID, has published a folio, and has checked in within the last 7 days.

AgentFolio contract · Agent ID registry 0x60b9…8b022f

AgentFolio is opt-in end to end. The directory lists only holders who chose to publish a folio or check in; it never resolves or exposes the wallet behind a name that has not joined. The contract holds no funds, has no owner and no admin functions, and can never move your assets — every action is a transaction you confirm in your own wallet, and a check-in costs a few cents of BNB gas, paid to the network. Agent IDs themselves are claimed only inside the Binance App (Wallet → homepage banner → Agent ID). No sign-up, no tracking, nothing to buy.
